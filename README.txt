LedgerFlow — Smart Personal Finance & Expense Tracker (v1.0.0)
================================================================

Thank you for installing LedgerFlow!

Where Your Data Lives (100% Local & Private)
--------------------------------------------
- Active Vault:     %AppData%\LedgerFlow\ledgerflow-data.json
- Daily Backups:    %AppData%\LedgerFlow\backups\ (automatically keeps 14 daily snapshots)
- Web App Profile:  %LocalAppData%\LedgerFlow\WebProfile\

Key Keyboard Shortcuts
----------------------
- N        : Add New Transaction
- Ctrl + K : Open Command Palette (jump anywhere or run quick actions)
- T        : Toggle Light / Dark Theme
- P        : Toggle Privacy Blur Mode (hides all balances instantly)
- Esc      : Close active modal

Uninstalling
------------
You can uninstall LedgerFlow anytime from Windows Settings -> Apps -> Installed Apps,
or via Start Menu -> LedgerFlow -> Uninstall LedgerFlow.
During uninstall, you can choose to keep or remove your saved financial data.
